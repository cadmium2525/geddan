# GEDDAN DRAW

描いた線の「荒ぶり」を、描いたキャラクターのダンスに変換するブラウザゲーム（MVP）。

## 遊び方

1. **キャラを描く**：左（スマホは上）のキャンバスに自由に描く。うすいガイド（頭・胴・腕・脚）に重ねると、きれいに動きます。
   - ✏️ ペン／🪣 バケツ／🧽 消しゴム（触れた線・塗りをまるごと消す）
   - 14色＋自由色（カラーピッカー）、太さ
   - バケツ：線で囲まれた所を塗る。塗りも骨に付いて一緒に動く。外側をタップすると背景色（ダンス画面の背景にもなる）
   - 戻す／やり直す（Ctrl+Z／Ctrl+Y）、全部消す、サンプルキャラ
   - 「骨格を絵に合わせる」：描いた絵の大きさ・位置に骨格を自動で合わせる
   - 「関節を調整」：関節の点をドラッグして、絵の手足の位置に合わせる
2. **一筆書きの線を描く**：グルグル・ジグザグ・急加速など自由に。描く速さも記録されます。
3. **▶ 踊らせる**：線の特徴から振り付けを作って再生。BGM を選べます（おまかせ＝線で曲が決まる）。
   - 🎬 **動画を作る**：ダンスを MP4 で書き出し（対応していないブラウザでは WebM）。
   - 書き出した動画は、投稿文（タグ・URL 入り）とセットでスマホの共有シートから SNS へ。X / Threads / Bluesky / LINE の投稿画面を開くボタンもあります。
   - 📷 PNG 保存、🔊 音のオン／オフ

## 線の特徴 → ダンスの対応

| 線の特徴 | 変換する動き |
| --- | --- |
| 描画速度 | 手足の振れ幅・上下バウンス・テンポ（BPM）。急加速で「荒ぶり」（手足が伸びる＋ズーム＋集中線） |
| 曲率／折れ角 | 胴体のひねり・頭の傾き・首のび |
| 線の方向 | 体の傾き・腕を向ける方向 |
| 旋回・ループ | その場回転・腕のぶん回し・逆さま |
| 線の長さ／点数 | 振り付けの拍数（ループの長さ） |

線の形をキャラの移動経路には使わず、線の「動きの特徴」を全身のアニメーションに割り当てています。

## しくみ

- HTML + CSS + Vanilla JavaScript、Canvas 2D API、Pointer Events（スマホ・PC 両対応）
- 描いた線の各点を近い骨（頭・胴・腕・脚の 16 本）に重み付けで紐付け、骨と一緒に変形させる（スキニング）。領域を切り分けないので切れ目が出にくく、手足はゴムのように伸び縮みします。
- 線は「座標＋時刻」の点列として記録し、等間隔に再サンプルして速度・方向・曲がり・ループを計算 → 拍ごとにキーフレームを生成。
- 演出：コマ打ち（12fps）・線のゆらぎ・残像・モーションライン・集中線・カメラズーム。
- BGM は著作権の切れたクラシック（オッフェンバック「天国と地獄」、グリーグ「山の魔王の宮殿にて」、モーツァルト「アイネ・クライネ・ナハトムジーク」）を自作アレンジしたもの。[かなでる（mp4mp3/daw）](https://github.com/cadmium2525/mp4mp3) の曲 JSON で作り、`bgm/gen.mjs` が元データ。線の速さで再生速度（テンポ）が 0.85〜1.2 倍に変わります。
- 効果音・「ビートだけ」の音は WebAudio で合成。
- 動画は MediaRecorder（canvas の映像＋WebAudio の音）で書き出し、Web Share API で動画と投稿文を共有。
- 外部ライブラリ・サーバー通信・課金 API・認証・DB なし。ファイルは `index.html` と BGM（`bgm/*.mp3`）だけ。

## ローカルで動かす

`index.html` をブラウザで開くだけで動きます（BGM はファイルを直接開くと読み込めないので、`python3 -m http.server` などで開くか GitHub Pages で確認してください。読み込めないときはビートで踊ります）。

## GitHub Pages で公開

1. このリポジトリを Public にする
2. Settings → Pages → Build and deployment → **Deploy from a branch** → `main` / `(root)` を選んで保存
3. `https://<GitHubユーザー名>.github.io/<リポジトリ名>/` を開いて、スマホと PC で動作確認

`.nojekyll` は Jekyll の処理を止めて、ファイルをそのまま配信するためのものです。
